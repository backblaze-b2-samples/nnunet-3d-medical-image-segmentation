# Feature: Model checkpoints on B2

## Purpose
Demonstrate "the model lives on B2": a real short nnU-Net training run mints a
checkpoint at seed time, archives it to B2, and inference resolves the model
from a local cache or pulls it from B2 — so any host can serve inference
without retraining.

## Used By
- CLI: `pnpm run seed` (mints + uploads)
- API: `POST /jobs/{job_id}/run` (resolves the model)

## Core Functions
- `app/service/training.py::train_demo_model` — preprocess + short train (~1 epoch, ~25 iters)
- `app/service/segmentation.py::ensure_model_available` — cache-or-pull
- `scripts/seed_b2.py::_upload_checkpoint` — tar + upload to `checkpoints/`

## Inputs
- The synthetic raw dataset under `nnUNet_raw/` (generated by the seed)

## Outputs
- Local: `.data/nnUNet_results/Dataset001_DemoLesion/.../checkpoint_final.pth` (gitignored)
- B2: `checkpoints/Dataset001_DemoLesion.tar.gz`

## Flow
- Seed generates synthetic labeled volumes and writes the nnU-Net raw dataset
- `train_demo_model()` runs fingerprint → plan → preprocess → short train
- The results dir is tarred and uploaded to `checkpoints/`
- At inference, if the local checkpoint is absent, the tarball is pulled from B2 and extracted before predicting

## Edge Cases
- Checkpoint already present (local or B2) → seed skips training (idempotent) unless `--force`
- torch ≥ 2.6 breaks nnU-Net 2.5.x's PolyLRScheduler → torch is pinned `<2.6` in requirements
- nnU-Net env dirs (`nnUNet_raw`/`nnUNet_preprocessed`/`nnUNet_results`) live under gitignored `.data/`

## Verification
- Test files: `services/api/live_tests/test_nnunet_roundtrip.py`
- Focused verify command: `RUN_LIVE_NNUNET_TESTS=1 pnpm --dir services/api exec pytest live_tests/test_nnunet_roundtrip.py -m live`
- Default pre-PR verify command: `pnpm verify`
- Pass criteria: training writes `checkpoint_final.pth`; a fresh process pulls it from B2 and predicts
